# Advanced Task Planner

A lightweight browser-based task planner for organizing daily work with priorities, due dates, search, filtering, completion tracking, and theme support.

## Features

- Create, edit, and delete tasks
- Assign priorities and due dates
- Search and filter tasks
- Mark tasks as completed
- Light and dark modes
- Responsive interface

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Getting started

Open `index.html` in a browser or serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Roadmap

Potential improvements include persistent storage, task categories, reminders, and cross-device synchronization.
